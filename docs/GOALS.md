# 项目目标与范围

## 背景

求职者（27 届硕，浙江工业大学计算机）需要一个让面试官记住自己的方式。在简历末尾放一个带 AI 对话功能的个人主页链接——这件事本身就稀缺，上面有个能聊天的 AI 更稀缺。

## 核心目标

**让面试官在 30 秒内产生"这人有点意思"的印象。**

具体来说：
1. 个人主页第一屏展示核心简历信息（正经内容占 80%）
2. 右下角有个 AI 小头像，点击弹出聊天框（彩蛋占 20%）
3. 面试官可以向 AI 提问求职者的项目经历、技能、GameJam 经历等
4. AI 回答严格基于简历知识库，不会胡说八道

## 功能清单

### MVP（2 天内必须完成）

1. **静态主页**：简历内容 + 项目卡片 + 关键经历，一页到底
2. **AI 形象**：SVG / emoji / 像素风头像，有呼吸动画即可
3. **AI 对话**：
   - 调用 DeepSeek V4 Flash API（暂定，模型可换）
   - RAG 检索简历知识库 → 拼 prompt → 流式输出
   - prompt 约束：知识库有就答，没有就说"这个你可以直接问我本人哈～"
   - 前端简约聊天框，支持流式逐字输出
4. **部署上线**：Vercel + 自定义域名，HTTPS 自带

### 明确不做

- ❌ 不搞 3D 形象 / Live2D —— 耗时且喧宾夺主
- ❌ 不做用户登录 / 多轮对话保存 —— 面试官就看一眼，不需要
- ❌ 不做多模型切换 —— 一个模型够了
- ❌ 不接语音 / 图片 —— MVP 纯文本
- ❌ 不做后台管理面板 —— 简历改内容直接改 `knowledge/resume.md`
- ❌ 不买服务器 —— Vercel + Render 免费兜底

## 成功标准

- [ ] 面试官打开 `curioustrea.fun`，3 秒内看到简历内容
- [ ] AI 聊天能流畅回答 90% 简历相关问题
- [ ] AI 遇到不知道的问题时，正确触发兜底回复
- [ ] 全站加载 < 3 秒（含 AI 头像动画）
- [ ] 手机端也能正常看（响应式）
